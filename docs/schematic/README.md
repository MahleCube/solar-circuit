## 対象版

保存版 `C07_named_nodes_20261030_r06`。2026年10月30日に確認した回路図を、2026年10月31日に登録しています。PDFと編集用データは、確認済みの保存版と同一のファイルです。

## KiCadで開く

リポジトリ全体をダウンロードし、KiCad 10で `hardware/c07/project/C07_Solar.kicad_pro` を開いてください。回路図の入口は同じフォルダの `C07_Solar.kicad_sch` です。

子シート2枚、`sym-lib-table`、`libraries/` の専用シンボル5ファイルが必要です。これらを同じ配置のまま保持してください。専用シンボルの参照はプロジェクト相対パスです。

## 確認した範囲

- 188部品、189配置ユニット、560端子、133ネットを確認。
- 修正前後で部品情報と端子間の電気的な接続関係を維持。
- ERCはエラー0・警告0。
- 登録用フォルダへ移設したデータからも、同じ188部品・560端子・133ネットを出力し、ERCはエラー0・警告0。

ここでの確認は回路図データと接続関係を対象としています。回路の電気的性能、実機動作、PCB配線、製造適合性の確認は含みません。
