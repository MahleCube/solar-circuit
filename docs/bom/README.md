Q3A・Q3Bは1個のデュアルMOSFETに含まれるため、購入数量は1個です。回路全体を囲む枠、IC内部の解析要素、端子、接続ラベルは部品点数に含めていません。型番未選定の行は、公称値を記載して識別できるようにしています。

図面に記載されていない基板、配線、端子台、ヒューズホルダー、放熱器、固定具は、この部品表には含めていません。価格は未収録です。
