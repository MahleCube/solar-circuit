# r04

作者が設計中のc07を最適制御するために開発中の制御方式です。RP2040向けにCとRaspberry Pi Pico SDKで実装しています。

**IncCond → パネル電圧目標 → 電圧PID → L1電流目標 → 電流PI → Duty** の順に調整します。通常充電はデッドタイム付き同期整流、起動・軽負荷はダイオード還流です。PWMは50 kHzで連続生成し、Dutyは周期の区切りで更新します。追従制御は601 µs周期。MPPTは背景で計算し、電流制御を待たせません。

USBシリアルの `ARM`（改行終端）で起動します。PV保護回路とゲート電源を許可し、電池側のLTC4364に動作を許可して低電流で出力を立ち上げます。出力電圧を制限しながら保護ICの起動を待ち、通常充電へ移ります。`DISARM`で停止し、電源投入直後は指令待ちです。

通常の日照不足は出力を切って回復を待ちます。残留入力電圧も確認してから、PV保護回路の解除手順から再開します。正常なDuty更新ではPWMを停止・再初期化しません。制御更新の途絶は別のPIO監視で検出し、出力を停止します。PIOは停止原因を保持し、過電流・電源異常・処理期限切れは解除操作まで停止を保持します。

15 Aは充電電流の目標上限です。U5の測定温度により65℃から電流を抑え、80℃で停止します。一周期の推定損失を固定のW数と比較する停止判定は使用していません。

ポートフォリオ用の設計実装です。[設計設定](src/commissioning.h)のゲート遅延や測定誤差はモデル上の前提であり、実測値ではありません。保護ICを含む実基板の応答、校正、放熱条件の確認は残っています。
