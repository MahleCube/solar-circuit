設計中のc07を最適制御するために開発中の制御方式です。RP2040向けにCで実装しています。

**IncCond → パネル電圧目標 → 電圧PID → L1電流目標 → 電流PI → Duty** の順に調整します。
通常充電はデッドタイム付き同期整流、起動・軽負荷はダイオード還流です。
PWMは50 kHzで連続生成し、Dutyは周期の区切りで更新します。
追従制御は601 µs周期。MPPTは背景で計算し、電流制御を待たせません。
