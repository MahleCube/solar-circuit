# r04

作者が設計中のc07を最適制御するために開発中の制御方式です。RP2040向けにCとRaspberry Pi Pico SDKで実装しています。

制御の流れは **IncCond → パネル電圧目標 → 電圧PID → L1電流目標 → 電流PI → Duty** です。通常充電はデッドタイム付き同期整流、起動・軽負荷はダイオード還流へ切り替えます。PWMは50 kHz、制御は601 µs周期です。MPPTの判定不能が続くと、近傍の電圧で再測定します。

PIOによる独立した異常監視と有限時間のPWM許可を備えています。ソフトウェアが検出した入力不足は出力を切って回復を待ちます。PV停止ラッチなどの保護通知が先に届いた場合は、解除操作まで停止を保持します。

**実機運転の許可は未設定です。** ゲート遅延、計測校正、電流・熱の動作範囲が未認定のため、既定では電源経路もPWMも有効になりません。モデルでの確認を実機の安全保証とはしていません。
