# C07 PCB

r26（2026-11-06）。264 × 136 mm、6層の配置・配線を仕上げた設計版です。Pico Wの交換式ソケット、IC端子間を迂回する配線、M3用取付穴4か所を反映しています。

KiCad 10で `C07_Solar.kicad_pro` を開き、PCB Editorで `C07_Solar.kicad_pcb` を開いてください。対応する回路図、カスタムライブラリ、プロジェクト内3Dモデルを同梱しています。KiCad 10の標準フットプリント・3Dモデルライブラリも必要です。

実機製作・性能検証・製造承認は未実施です。放熱器と絶縁・固定具、外部線材と保持、筐体支持、製造公差などの条件は未確定です。

ライブラリ・3Dモデルの帰属と利用条件は [LICENSES](LICENSES/) および各ファイルのヘッダ、同梱メーカー免責文を参照してください。
