# 太陽光充電システム 設計ポートフォリオ

RP2040とMicroPythonによる制御を想定した、太陽光充電システムの設計演習です。ソーラーパネルから蓄電池への充電までを対象とし、実機制作は対象外としています。

採用選考で設計内容を確認していただくための資料を、このリポジトリに整理します。

## 掲載資料

| 資料 | 内容 |
| --- | --- |
| [部品表（c07、Excel）](docs/bom/c07_BOM.xlsx) | 型番別の集計と部品番号別の明細。部品番号、仕様、数量、用途、型番の選定状態を収録。 |
| [部品表の対象範囲・数え方](docs/bom/README.md) | 参照した回路版、数量の数え方、未選定・候補部品の扱い。 |

部品表は2026年10月29日時点の保存済みc07回路図をもとに作成しています。型番未選定・候補部品を含む設計段階の資料です。
