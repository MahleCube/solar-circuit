# 太陽光充電システム

この制作はオフグリッド用太陽光発電システムの設計のポートフォリオです。  
シミュレーションでのみ動作の確認を行っており実機の作成まで行っていません。

- 400ｗのパネルを二枚直列に繋いだ800ｗの充電システムです。
- バッテリーには51.2Vのリン酸鉄リチウムイオンバッテリーを採用しています。
- HIGH側、LOW側にNchMOSFetを設置した同期整流、BUCK方式です。
- 保護ICによるハードウェア保護回路をパネル側バッテリー側両側に使用

ソーラーパネルから制御回路を通ってバッテリーに充電するまでの部分が制作のフォーカスとなります。

## プログラムの効率

- MPP追従性能　**99%前後**
- 日射量が0.03秒ごとに急変する状況で　**96,977％**

## 回路の効率

- 750w時　95.7%
- 600w時　96.1%
- **300w時　96.5%**
- 100w時　94.0%
- 50w時　90.0%
- *10w時 63.0%　発電量が少ない時に急激に効率が下がる*

---

2023年　京都市南区の特定地点での放射照度から計算する

- パネルから取り出せる理論上最大電力量は　**1,309kWh**
- 年間の放射照度を1時間ごとに効率計算を行った発電量　**1,248.9kWh**

**→年間の効率期待値　95.4%**

ただし、今回は用途を指定していない。  
全ての充電電力を一度バッテリーに入れてからAC電力として取り出す場合の電力量は  
バッテリーの充放電効率とAC変換効率をかける必要がある。

> ACで使える電力量 = バッテリーへの充電電力量　×　充放電効率 × AC変換効率

今回の回路では電気を取り出す仕組みまでは作成していないので暫定的に以下のようにありそうな値を代入して計算を行う。

- 充放電効率 92%
- AC変換効率　94%　と仮定する。

**1,248 × 0.92 × 0.94 = 大体1,079kWh / 年**

---

設計した充電システムの実用性を検討するため、年間充電量と機器費用から経済性も概算しました。

**2026年11月7日時点の流通価格にて計算**

- 回路価格　87,060円
- 400Wソーラーパネル　62,100円×2
- 51,2V 100Ahリチウムイオンバッテリー　118,181円

**合計　329,441円**

電力の料金は会社やプランによって変動があるが関西電力の各種プランの中間程度の価格  
23円/kWhと仮置きすると年間**24840円/年**

無駄なく電気を消費したとして制作費を回収できるまでの期間は**13年3ヶ月**となる。

この試算から、経済性を評価するには、回路効率に加えて、使用する機器、消費する時間帯、必要な蓄電池容量まで含めて設計する必要があると考えられます。
